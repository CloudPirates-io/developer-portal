# Managed Observability

**Full transparency, zero effort** - Our Managed Observability Platform provides comprehensive monitoring, logging, tracing, and alerting for your cloud-native infrastructure through a simple, single-chart installation. Built on 15+ years of experience in high-availability and distributed systems, the platform delivers detailed insights into cluster health, resource utilization, and system performance.

## What is Managed Observability?

The CloudPirates Managed Observability Platform is a fully managed SaaS solution that eliminates the complexity of setting up and maintaining your own observability infrastructure. By deploying our lightweight ClusterPirate agent in your Kubernetes clusters, you gain access to a comprehensive observability stack with zero operational overhead.

## How It Works

1. **Portal Setup**: Register at [portal.cloudpirates.io](https://portal.cloudpirates.io) and create your workspace
2. **Instance Creation**: Set up an observability instance for your organization
3. **Cluster Registration**: Create clusters in the portal to obtain access tokens
4. **Agent Deployment**: Install the ClusterPirate helm chart with your access token
5. **Insights & Monitoring**: Access comprehensive monitoring data through the web console

## Getting Started

Ready to start monitoring your clusters? Follow our [Setup Instructions](./setup-instructions.md) to get up and running in minutes.

The setup process involves:
- Portal registration and workspace creation
- Observability instance configuration  
- Single helm chart installation using the ClusterPirate agent
- Immediate access to monitoring data and insights
